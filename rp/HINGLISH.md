# Correct Roman Hindi (all `hi.json`)

Hindi grammar. Roman letters. Everyday speech. **Not** Devanagari. **Not** English with yaar stuck on.

## Pronouns

Player is male. Always:

| | Use | Never mix |
|--|-----|-----------|
| you | **tum / tumhe / tumse / tumhara / tumhari** | tu, tera, tujhe |
| I | **main** | mein (place only) |
| she | **wo** | |
| we | **hum** | |

Women (Yui, Lucy, Mei, Sasha, Elara): feminine verbs — `karti hai`, `rahi thi`, `gayi`, `karti hui`.

Narrator to player: `tum … rahe the` / `tum … ho`.

## Verbs (must finish the clause)

| Sense | Form |
|-------|------|
| past, male you | `kiya` / `rahe the` / `the` |
| past, she | `ki` / `rahi thi` / `thi` |
| present | `karte ho` / `karti hai` / `hai` |
| copula | do not drop `tha/thi/the/hai/ho` on a full sentence |

Short cinematic beats can stay fragments (`Phir darwaza khula.`). Longer lines need a verb.

## Postpositions

- `mein` = in
- `pe` / `par` = on
- `se` = from / with
- `ko` = object
- `ke liye` = **only** real purpose (“for the mission”). Never English “for the screaming” → `cheekhon ke liye`.

## Word order

Hindi SOV. Split long English sentences into two short Hindi ones. Do not glue English tails onto Hindi.

**Wrong:** `waiting room mein halki si eucalyptus aur kuch aur mehangi khushboo`  
**Right:** `waiting room mein halki si eucalyptus aur thodi mehengi si khushboo aa rahi thi.`

**Wrong:** `Doctor ko maine aisa nahi socha tha`  
**Right:** `Maine apne doctor ko aisa imagine nahi kiya tha.`

**Wrong:** `cheekhon ke liye ruki nahi`  
**Right:** `cheekhon pe ruki nahi.`

## Loanwords (keep, don’t Hindi-fy)

clinic, nurse, doctor, checkup, patient, like, DM, selfie, file, cover, mission, husband (Sasha tease), gala, safehouse.

Never: `vorn`, `haimar`, `adhyay` (use Chapter).

Node ids, `next`, `set`, media URLs, `*emphasis*` counts, emojis. Heat = English.

## Gold: Yui CH01

Subtitle: `Usne tumhari purani photo like ki thi…`

```
Notification aaya jab tum bistar pe lete the, aadhe soye, social media scroll kar rahe the.
Kisi ne tumhari ek purani photo like ki thi.
Naya post nahi. Kal wala nahi. Lagbhag teen mahine purani photo.
Curiosity hui, tumne notification pe tap kiya.
```

Choice: `Likes ke liye thanks. Socha nahi tha koi profile itni gehraai tak jayega.`

## Gold: Lucy CH01

Subtitle: `Wo tumhe bahut, bahut achhe se examine karegi…`

```
Tum isko mahino se taal rahe the. Clinic ne kaha tha — *routine full physical* — jo zimmedaar log bas kar lete hain.
Nayi practice thi. Naram roshni, gunguni deewarein, waiting room mein halki si eucalyptus aur thodi mehengi si khushboo aa rahi thi.
```

Choice: `Sach bataun, main thoda ghabraya hua hoon. Maine apne doctor ko aisa imagine nahi kiya tha.`
