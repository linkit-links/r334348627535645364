# Yui localization style

## Goal

Simple everyday language that stays **flirty / sexy / warm** like English. Chat / dating-app energy, not literary.

## Voice split

| Voice | How it should feel |
|-------|--------------------|
| **narrator** | Second-person “you”, cinematic but short sentences |
| **Yui** (no `speaker` or her lines) | Soft, teasing, a little shy, increasingly bold |

## Heat curve

- CH01–03: soft tease, DMs, photos
- CH04–05: real date + studio confidence
- CH06–08: late night, body, jealousy, almost-kiss
- CH09–10: confession, morning-after intimacy

Do **not** sanitize. Do **not** go more explicit than EN.

## Reading level

- Ages ~16–30 native speakers should get every line instantly
- Prefer spoken vocabulary over formal / textbook
- Indonesian: santai, menggoda  
- Portuguese: informal **Brazil** (você, tá, né) — not European  
- Russian: простой разговорный, игривый  
- Hindi: **Correct Roman Hindi** — see `rp/HINGLISH.md`. tum/tumhara only, not tu. like/DM/selfie stay English.

## Never change

- Graph ids, `next`, `speaker`, media URLs  
- Emojis placement (similar)  
- Line breaks as separate `lines[]` entries  
- Name **Yui**
