   ```json
     "speaker": "...",
     "lines": [...],
     "imageUrl": "https://linkit-links.github.io/r334348627535645364/rp/lingerie_thief/filename.webp",
     "next": "..."
   }
   ```

2. **Placement priority:**
   - At key story moments (sex scenes, punishments, reveals)
   - At chapter climaxes
   - After significant transformations
   - When new equipment is introduced

## How to Update en.json

1. Open `en.json` in a text editor
2. Search for the target node ID (e.g., "CH01_MERGE3")
3. Add the `"imageUrl"` property after the `"lines"` array
4. Ensure proper JSON syntax (comma after the imageUrl line if there's a "next" property)
5. Validate JSON before saving
